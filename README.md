# Кварта

Лендинг обжарки в Минске. Статика на Astro, форма — React. Заявки принимает Hono, хранит PostgreSQL через Drizzle. Повтор в течение суток обновляет ту же заявку, после суток создаётся новая. Интерес — подписка, разовый заказ или вопрос. Телефон проверяет сервер как белорусский.

Сайт: https://coffee-house-website-wine.vercel.app/
Репозиторий: https://github.com/dvoronin-tech/coffee-house

## Что делал я

Собрал структуру и тон по Slow Brew, зафиксировал палитру и шрифты. Секции принимал по одной и сам вливал. «Историю» правил сам. Бэкенд заявок и Telegram довёл отдельно. Требования к форме проговорил по пунктам и доделал за AI детали

Проектировал архитектуру, проводил grilling, review и доработку кода. Так же написал структуру back end, дальше boiler plate code писал AI. 

## Что делал ИИ

Вёрстку секций, адаптацию, связку формы с сервером. Журнал работы с AI: `ai-worklog.md` в Context проекта. Это выжимка, не сырой экспорт сессии.

## Где ИИ ошибся

Стили Astro писал как у React (clsx и SCSS Modules). Правило было слишком общим, я сузил его до `.tsx`, файлы переписаны на `<style>`.

Трогал git без просьбы. Дальше ветки двигаются только когда я явно прошу.

Код «заявка создана» сначала брался из чтения до записи: два одновременных запроса могли оба сказать, что заявка новая. Исправлено: код берётся из самой записи.

Так же сразу создал back end с кривой структурой. Её пришлось доделывать в ручную.
