# 05: Записать аналитику один раз

**What to build:** Первый годный объект аналитики сохраняется вместе с заявкой и больше не заменяется. Пустая, отсутствующая или негодная аналитика не мешает сохранить имя, телефон и заметку и не затирает уже записанный первый визит.

**Blocked by:** 04: Обновить заявку тем же id

**Status:** resolved

- [x] Непустой объект аналитики размером не больше 8192 байт UTF-8 у `JSON.stringify` сохраняется на первой успешной отправке, где аналитика ещё пустая
- [x] Ключи внутри сохранённой аналитики лежат как в запросе: сервер их не выкидывает и не дописывает
- [x] Уже записанная аналитика не заменяется новой при повторе. Имя, телефон и заметка при этом обновляются
- [x] Если аналитика была пустой, годный объект на повторе заполняет её. Ответ по-прежнему `UPDATED`, если строка уже была, и `CREATED`, если это первая строка
- [x] Отсутствующая аналитика, `null`, пустой объект, массив, строка, число и объект больше 8192 байт не записываются и не отклоняют заявку
- [x] Кода `INVALID_ANALYTICS` нет. Отказы по id, имени, телефону и заметке по-прежнему ничего не меняют, включая уже записанную аналитику
- [x] Тип маршрута, который импортирует сайт, принимает аналитику в теле
- [x] Автоматических тестов нет

## Comments

Реализовано на ветке `feat/hono`. Первая годная аналитика больше не заменяется.
