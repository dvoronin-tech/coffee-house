# 02: Сохранить новую заявку

**What to build:** Разработчик одной командой compose поднимает только PostgreSQL, отдельной командой применяет схему и на хосте запускает сервер. Сайт отправляет новую заявку одним методом: имя, телефон и необязательная заметка сохраняются, в ответе код создания. Сайт может импортировать тип этого маршрута. Форма на сайте по-прежнему не подключена.

**Blocked by:** 01: Перенести сайт в пакет website

**Status:** ready-for-agent

- [ ] Compose в корне поднимает только PostgreSQL 17, порт 5432, база `kvarta`, пользователь `kvarta`, пароль `kvarta`, данные в volume. Сервера в compose нет
- [ ] Сервер — Hono на Node, слушает порт из `PORT`, по умолчанию 3000, и запускается на хосте отдельно от базы
- [ ] `DATABASE_URL`, `WEB_ORIGIN` и `PORT` читаются из окружения сервера. Локальный адрес базы — `postgresql://kvarta:kvarta@localhost:5432/kvarta`. Локальный origin сайта — `http://localhost:4321`. В git есть только пример окружения, без заполненного секретного файла
- [ ] Origin из `WEB_ORIGIN` проходит CORS
- [ ] Схема — SQL-миграции Drizzle. Их применяет отдельная команда, не старт сервера
- [ ] Таблица заявки называется `records`. Колонки: `id` text, первичный ключ; `name` text, не null; `phone` text, не null; `note` text, null; `analytics` jsonb, null; `created_at` и `updated_at` timestamptz, не null. Время ставит PostgreSQL
- [ ] Единственный маршрут — `POST /send-order`. Успех — HTTP 200 и тело `{ code }` без id
- [ ] Новый id от 1 до 128 символов сохраняется как пришёл, без обрезки и без проверки формата UUID. Ответ `CREATED`
- [ ] Имя обрезается по краям и сохраняется. Заметка обрезается по краям. Пустая заметка, заметка из одних пробелов и отсутствующая заметка сохраняются как пустые (`null`)
- [ ] Действительный белорусский телефон, городской или мобильный, сохраняется как E.164. Тот же телефон с другим id создаёт другую заявку
- [ ] У новой заявки проставлены время создания и время изменения. Аналитика остаётся пустой
- [ ] Неожиданный сбой сохранения отвечает HTTP 500 и `{ code: "INTERNAL_SERVER_ERROR" }`
- [ ] Пакет website зависит от пакета order-server и может импортировать тип маршрута без отдельной генерации клиента и без предварительной сборки деклараций. Форма заявки не меняется
- [ ] Повтор с тем же id, коды отказа по полям и запись аналитики в этот тикет не входят
- [ ] Автоматических тестов нет
