# Аналитика пишется один раз

Аналитика заявки по умолчанию пустая. Первый непустой объект сохраняется и дальше не меняется, даже если повторная отправка принесёт другой. Имя, телефон и заметка при этом обновляются. Пустой объект, `null`, отсутствие поля, необъект и объект больше 8 КБ не заполняют аналитику и не мешают сохранить заявку. 8 КБ — это 8192 байта UTF-8 у `JSON.stringify`. Ошибочные метки первого визита новой отправкой не исправить.

## Considered Options

- Заменять аналитику при каждой отправке. Отклонено: первый визит должен остаться, даже если человек вернётся без меток.
- Отклонять всю заявку из-за плохой аналитики. Отклонено: заявка сохраняется, аналитика в этом случае просто не пишется.
