# Таблица заявки называется records

Заявка хранится в таблице `records`: `id` text, `name`, `phone`, `note`, `analytics`, `created_at`, `updated_at`. Имя таблицы не совпадает ни со словом «заявка», ни с путём `/send-order`. В языке проекта запись остаётся заявкой.

## Considered Options

- `applications`. Отклонено: таблица называется `records`.
