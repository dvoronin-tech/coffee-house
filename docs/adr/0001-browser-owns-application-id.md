# Идентичность заявки задаёт браузер

Заявка узнаётся по строке, которую сайт создаёт один раз через crypto и хранит в localStorage. Сервер хранит её как есть и не проверяет формат UUID. Пустая строка, не-строка и строка длиннее 128 символов отклоняются. Сервер по этому id обновляет строку или создаёт новую. Логина нет: знание id достаточно, чтобы перезаписать заявку. Телефон не уникален, поэтому тот же человек в другом браузере — это другая заявка. Время создания не меняется. Повторная отправка обновляет имя, телефон, заметку и время изменения. Прошлые значения этих полей не хранятся.

## Considered Options

- Число миллисекунд, `Date.now()`. Отклонено: id — строка из crypto.
- Новая строка на каждую отправку. Отклонено: повтор из того же браузера должен исправлять ту же заявку.
- Уникальный телефон. Отклонено: исправление заявки не должно упираться в занятый номер, а другой браузер — это другая заявка.
